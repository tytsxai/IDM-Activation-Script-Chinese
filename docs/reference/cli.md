# 命令行接口契约 / CLI Reference

本项目没有 HTTP API。对外的可编程接口只有一个：**`IAS.cmd` 的命令行**——参数、退出码、日志文件、标准输出。
本文是这个接口的契约文档，脚本化调用请以此为准。

> 改动本文覆盖的任何一项，都必须同步 [文档同步规则](../doc-sync.md) 中列出的文件；`tools/check-docs.ps1` 会在 CI 中校验参数与退出码两项是否漏改。

- 实现位置：[`IAS.cmd`](../../IAS.cmd) 参数解析段（`set _args=%*` 起）
- 入口封装：[`开始激活.cmd`](../../开始激活.cmd) 把收到的参数原样透传给 `IAS.cmd`

## 调用形式

```cmd
IAS.cmd [动作参数] [/silent | /quiet] [/log | /log=路径]
```

- 必须在**管理员**权限下调用。非管理员时 `IAS.cmd` 会用 `Start-Process -Verb RunAs` 弹 UAC 重开进程，原进程立即返回，**拿不到真实退出码**。
- 参数不区分大小写。
- 参数解析前会先剥掉命令行里的所有双引号，再按空格切分。因此**任何参数值都不能含空格**。
- 不带任何动作参数且不带 `/silent` 时进入交互菜单。

## 动作参数

一次调用只应带一个动作参数。它们与主菜单项一一对应。

| 参数 | 菜单项 | 行为 | 是否联网 | 是否写注册表 |
| --- | --- | --- | --- | --- |
| `/frz` | `[1]` | 冻结试用期：锁定 IDM 记录试用状态的 CLSID 键，不写序列号 | 是 | 是 |
| `/act` | `[2]` | 激活：同 `/frz`，并额外写入随机生成的姓名 / 邮箱 / 序列号 | 是 | 是 |
| `/res` | `[3]` | 重置：删除注册信息、试用计数与 CLSID 键，回到初始状态 | 否 | 是 |
| `/noupd` | `[4]` | 把 `CheckUpdtVM` 置 `0`，关闭 IDM 自动更新检查 | 否 | 是 |
| `/reupd` | `[5]` | 把 `CheckUpdtVM` 置 `1`，恢复 IDM 自动更新检查 | 否 | 是 |

行为细节：

- **同时给 `/noupd` 和 `/reupd` 时，`/noupd` 生效**（脚本显式把 `_reupd` 置 0）。
- 动作参数之间没有互斥校验。若同时给多个，实际执行顺序由分派语句决定：`/res` → `/noupd` → `/reupd` → `/act` → `/frz`，命中第一个后其余被忽略。**不要依赖这个顺序**，一次只传一个。
- `/frz` 与 `/act` 走同一段流程，只由内部变量 `frz` 区分是否执行注册信息写入。
- 也可以不传参数，改成编辑 `IAS.cmd` 头部的 `set _activate=0` 等开关（把 `0` 改成 `1`）。改了任一开关即等同于传了对应参数，脚本进入无人值守模式。

## 辅助参数

| 参数 | 说明 |
| --- | --- |
| `/silent` | 无人值守：不显示菜单、不等待按键、不做二次确认。别名 `/quiet`，两者完全等价 |
| `/log` | 开启日志，写到 `%SystemRoot%\Temp\IAS-<时间戳>.log` |
| `/log=路径` | 开启日志并写到指定文件。父目录不存在会自动创建；写不进去时提示并回退到默认位置 |

约束：

- **`/silent` 会自动开启日志**（`_silent=1` 时脚本强制 `_log=1`），不用再写 `/log`。这是有意的：静默运行出错时屏幕上什么都看不到，日志是唯一线索。
- **`/silent` 必须搭配动作参数**。只给 `/silent` 不给动作参数会以退出码 `2` 立即退出。
- **`/log=` 的路径不能含空格**。参数按空格切分，`/log=C:\My Logs\ias.log` 会被截断成 `C:\My`。
- `/log=` 后面留空（例如 `/log= /silent`）会被识别为无效路径并忽略，回退到默认位置。

## 内部参数（不要在脚本化调用中使用）

这些参数由脚本自己在重入时附加，不属于对外契约，随时可能变动：

| 参数 | 用途 |
| --- | --- |
| `-el` | 提权重入标记，防止 UAC 失败时无限循环拉起新进程 |
| `-qedit` | 跳过为关闭 QuickEdit 而做的 conhost 重入，直接在当前窗口继续 |
| `r1` | x86 进程在 x64 / ARM64 上重入到 `Sysnative` 后的标记 |
| `r2` | x64 进程在 ARM64 上重入到 `SysArm32` 后的标记 |

`-qedit` 是唯一一个人工使用有意义的：当 conhost 重入被安全软件或组策略拦截时，可以用
`IAS.cmd -qedit` 绕过（见 [运维与排错指南](../operations.md) 的「进不了菜单」一节）。CI 也用它跑交互菜单冒烟。

## 退出码

| 退出码 | 含义 | 触发场景（来自 `IAS.cmd` 中的 `call :set_exit`） |
| --- | --- | --- |
| `0` | 正常完成 | 冻结 / 激活 / 重置 / 更新开关执行成功；或从交互菜单正常退出 |
| `1` | 进入业务流程但未成功 | 未检测到 IDM 安装；无法连通 internetdownloadmanager.com；注册表值删除失败；注册表值写入失败；IDM 下载测试失败 |
| `2` | 环境或参数错误 | 静默模式缺动作参数；Windows 版本低于 7600；系统中找不到 `powershell.exe`；PowerShell 被策略阻止或非 FullLanguage；缺管理员权限；WMI / CIM 查询失败；未能获取当前用户 SID；无法写入 CLSID 分支；脚本从压缩包临时目录运行；脚本被改成 LF 换行或末尾缺空行 |

语义约定：

- **只记录第一个非零退出码**。`:set_exit` 在 `exit_code` 已非 0 时不再覆盖，因此拿到的是最早的失败原因，而不是最后一个。
- `0` 不等于「IDM 一定处于已激活状态」。它只表示脚本按预期跑完了自己那一段——例如 `/act` 写入的随机序列号是否被 IDM 服务端接受，脚本无从判断。
- 退出码 `1` 与 `2` 的区分标准是**是否已经进入业务分支**：`2` 表示还没开始干活就被环境挡住了，`1` 表示开始干了但没成。

## `开始激活.cmd` 的退出码

它是给人双击用的入口，退出码语义与 `IAS.cmd` 不同：

| 情况 | 退出码 |
| --- | --- |
| 已是管理员，自检通过并调用了 `IAS.cmd` | 原样透传 `IAS.cmd` 的退出码 |
| 自检发现问题，用户选择 `[N]` 退出 | `1` |
| 找不到同目录的 `IAS.cmd` | `1` |
| 找不到 `powershell.exe`，无法自动提权 | `1` |
| 不是管理员，弹 UAC 重开了新进程 | `0`（激活在新进程里跑，本进程无从得知结果） |

**所以：需要按退出码判断结果的自动化调用，必须以管理员身份直接执行 `IAS.cmd`，不要走 `开始激活.cmd`。**

## 标准输出约定

`IAS.cmd` 的输出是给人看的中文界面，**不是结构化输出**，请不要解析它：

- 输出编码是 GBK（代码页 936）。用 PowerShell 捕获时需要显式按 936 解码，否则中文全是乱码。
- 支持 ANSI 的控制台上会带转义序列（`_NCS=1`），不支持时走无颜色的纯文本分支（`_NCS=0`），**同一句话在两种模式下的输出并不逐字节相同**。
- 自动化判断请用退出码 + 日志文件，不要用 stdout 匹配。

日志文件是行式文本，格式固定：

```
[<日期> <时间>] <消息>
```

日期与时间来自 `%date%` / `%time%`，因此**格式随系统区域设置变化**，不要按固定格式解析时间戳。

## 调用示例

```cmd
:: 交互使用：双击 开始激活.cmd 即可，无需命令行

:: 冻结试用期（推荐），无人值守 + 日志
IAS.cmd /frz /silent /log=C:\Temp\ias.log

:: 重置后重新冻结（两次调用之间检查退出码）
IAS.cmd /res /silent /log=C:\Temp\ias-res.log
if %errorlevel% NEQ 0 exit /b %errorlevel%
IAS.cmd /frz /silent /log=C:\Temp\ias-frz.log

:: 关掉 IDM 的更新弹窗
IAS.cmd /noupd /silent
```

批量、多机与计划任务的编排方式见 [服务器 / 批量部署](../deployment/server.md)。
